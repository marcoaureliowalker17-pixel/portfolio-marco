# Portfólio de edição de vídeo — Marco de Pantufas

Site estático com identidade visual inspirada em uma plataforma de vídeos: catálogo de projetos, miniaturas, páginas para assistir, gameplay e informações de contato.

## Publicação

O site pode ser publicado no **GitHub Pages**, com a fonte definida como branch `main`, pasta `/ (root)`.

**Endereço após publicação:** https://marcoaureliowalker17-pixel.github.io/portfolio-marco/

## Estrutura

- `index.html`: página do canal
- `assistir.html`: páginas dos projetos
- `sobre.html`: informações e contatos
- `assets/`: banner, avatar e miniaturas
- `videos/`: vídeo de gameplay local
- `css/` e `js/`: estilos e comportamento

O vídeo do YouTube externo abre na plataforma original quando o player incorporado estiver bloqueado.

**Nota:** referências visuais à interface de plataformas de vídeo são parte de um projeto autoral de portfólio, sem vínculo oficial com YouTube ou Behance.
